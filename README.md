# 面談予約システム

## 概要

訓練校における受講者と相談員の面談予約を支援するWebアプリケーションです。

受講者は空いている面談枠を確認し予約できます。
相談員は予約状況の確認や、会議・授業などによる面談不可枠の管理を行えます。

本システムはポートフォリオとして、要件定義から設計・実装までの一連の開発プロセスを意識して作成しています。

***※ 2026-08-12現在、実装中であり、8月中の完成を目標としています。***

---

## 背景

現在ポリテクセンター宮城では、紙面上で面談予約を行っています。そのため現状、以下の課題があります。

- 空き時間の確認に手間がかかる
- 予約状況が把握しづらい

これらの課題を解決するため、本システムを開発します。

---

## 主な機能

### 受講者

- ログイン
- 面談可能枠の確認
- 面談予約
- 予約キャンセル
- 自身の予約確認

### 相談員

- ログイン
- 予約一覧確認
- 面談不可枠の登録
- 面談不可枠の解除

---

## システム仕様

### 面談枠

面談はあらかじめ定義されたコマ単位で管理します。

例

- 1限 09:00～09:30
- 2限 09:30～10:00
- 3限 10:00～10:30
- 4限 10:30～11:00

### 予約ルール

- 予約済みコマは予約不可
- 面談不可コマは予約不可
  
その他仕様に関する詳細は [要件定義書](./docs/要件定義書.md) をご覧ください。
