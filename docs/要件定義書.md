# 面談予約システム 要件定義書

## 1.システム概要
職業訓練の受講者がWeb上から面談予約を行い、相談員が予約状況を管理するシステムを構築する。
現在面談予約は紙ベースで行われているが、これをオンライン上から行えるようにすることで、確認や管理の手間を削減し、予約状況を可視化することを目的とする。

## 2.利用者
### 訓練受講者
* 面談可能日時の確認
* 面談予約
* 予約のキャンセル
* 自分の予約の確認
### 相談員
* 面談予約一覧確認
* 面談不可時間の登録･解除

## 3.業務ルール
### コマ管理
面談はあらかじめ定義されたコマ単位で行う。1コマ30分とする

|昼休み|

### 予約ルール
* すでにそのコマの予約が埋まっている場合予約は不可
* 相談員が面談不可時間として登録したコマは予約不可

## 4.機能要件

### ログイン機能
#### 受講者
* 受講者ID
* パスワード  
で認証する。  
IDとパスワードは事前に施設側で準備しているものとする。
#### 相談員
* 職員ID
* パスワード  
で認証する。  
こちらもIDとパスワードは事前に施設側で準備しているものとする。

### 面談予約機能
受講者は
* 相談員選択
* 日付選択
* コマ選択
を行い予約できる。

### 予約状況確認機能
受講者は相談員の予約状況を確認できる。  
日付と相談員を選択するとその日の空きコマの状況が見れる。

### 自分の予約の確認機能
受講者は自分の予約を確認できる。
#### 表示項目
* 日付
* 時間
* 担当相談員

### 予約取り消し機能
受講者は予約を取り消しできる。

### 面談不可設定機能
相談員は特定の日付･コマを面談不可として登録できる
#### 例
2026/08/08
3コマ  
理由:会議

### 予約一覧機能
相談員は自分に紐づく予約の一覧を確認できる。
#### 表示項目
* 受講者名
* 予約日時
* コマ

## 5.データモデル案
### users
* id
* name
* password
* role  
    * 受講者か相談員か
### slot_template
コマの定義
* id
* period_no  
    * 何コマ目か
* start_time
* end_time
### reservation
* id
* student_id
* counselor_id
* date
* slot_template_id
#### 制約
* teacher_id
* date
* slot_template_id  
の組み合わせを一意とする

### unavailable_slot
相談員の面談不可コマ
* id
* counselor_id
* date
* slot_template_id
* reason

## 6.空きコマ判定仕様
対象日について、  
予約済みコマ + 面談不可コマ  
を取得する。  
取得したコマ以外を予約可能として表示する。
#### 例
予約済:2限  
面談不可コマ:3限  
  
表示結果  
1限:◯
2限:✗
3限:✗
4限:◯
5限:◯
…
